🛠️ Production Architecture & Deployment Guide

1. The Two-Engine Architecture

This repository provides a complete dual deployment pipeline designed for optimal performance:

  • Vercel Serverless Platform: Hosts the high-throughput serverless API functions located in /api (querying PostgreSQL / fallback dataset) and the ultra-fast executive dashboard frontend in /public.
  • Streamlit Analytics Engine: Powered by app.py for interactive deep-dive analytics, multi-tab data science slicing, and Matplotlib/Plotly chart engines.

2. How to Deploy on Vercel Serverless

  1. Push this repository to GitHub.
  2. Sign in to Vercel and click Add New → Project.
  3. Import your interactive-dashboard repository.
  4. In Environment Variables, add: 
    DATABASE_URL = postgresql://neondb_owner:***@ep-spring-waterfall-az6eppdd-pooler.c-3.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
  5. Click Deploy. Vercel automatically configures the Python serverless runtime and serves the dashboard immediately.

3. How to Deploy the Native Streamlit App

  1. Visit Streamlit Community Cloud.
  2. Select your GitHub repo, branch main, and set main file to app.py.
  3. Under Advanced Settings → Secrets, paste your DATABASE_URL.
  4. Click Deploy for the full WebSocket-powered application.
